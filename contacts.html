Wanna Contribute?
Let's Build the Future of Optimization.

All contributions, big or small, are welcome! Whether you're a seasoned developer or just starting out, your input can help shape RustyLM into a powerful and efficient inference engine.

Why Collaborate?

RustyLM is an open-source, high-performance inference optimization library. We are looking for passionate developers skilled in Rust, C++/CUDA, SIMD optimizations, and machine learning runtime architecture or just passionate to learn it :)

Open Contribution Areas

  • Performance Kernels -> CPU, CUDA, ROCm, Apple Silicon
  • Quantization -> GGUF, AWQ, FP8 & new formats
  • Model Support -> Architectures, tokenizers & loaders
  • Runtime & Developer Tools -> CLI, Python API & tooling
  • Web Development -> Playground, monitoring & UI
  • Benchmarks -> Models, hardware & inference performance
  • Documentation & Examples
  • Testing & Bug Fixes
  • anything helps basically
