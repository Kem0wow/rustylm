Inference.
Hardened. By Rust.

A blazing fast, memory-safe LLM engine built for performance-critical local deployments. Zero telemetry, zero overhead.

Start Building GitHub Repository 
$ git clone https://github.com/Kem0wow/rustylm.git
$ cd rustylm
$ cargo build --release

Speed

Engineered in Rust for bare-metal performance and ultra-low latency.

Safety

Leverages Rust's borrow checker to ensure memory safety during heavy inference.

Accelerator

Native support for NVIDIA CUDA, Apple Metal, and AMD ROCm.

Hybrid Mode

Intelligent layer offloading between CPU and GPU for large models.

Local-First Engine

No Cloud. No Compromise.

rustylm is designed to run entirely on your hardware. From weight loading to token generation, you have absolute control over your data and environment.
